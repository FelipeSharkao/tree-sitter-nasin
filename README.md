# tree-sitter-nasin

[Nasin] grammar for [tree-sitter].

> [!WARNING]
>
> **Status: early/experimental.** Nasin itself is in early development. The
> grammar tracks the language and **no backward compatibility is promised** —
> rules, node names, and field names may change without notice.

[Nasin]: https://github.com/FelipeSharkao/nasin-lang
[tree-sitter]: https://github.com/tree-sitter/tree-sitter
